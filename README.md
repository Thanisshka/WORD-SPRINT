PROJECT DISCRIPTION:
Beyond Fate is an interactive website inspired by Thirukkural 620, which teaches the importance of persistence and continuous effort. The project uses a fun “Break the Wall” game where players face challenges, learn from failures, and keep trying until they overcome the obstacle. The growing tree represents growth through effort and perseverance. With a simple Tamil and English bilingual experience, the project makes the timeless message of Thirukkural engaging and easy to understand.
